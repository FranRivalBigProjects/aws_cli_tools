AWS CLI Tips

Use --output to change the response format
--output json (default), --output table for human-readable output, --output text for piping to shell scripts. Add --query with JMESPath to filter output: aws ec2 describe-instances --query 'Reservations[*].Instances[*].InstanceId' --output text

Use --profile to switch between AWS accounts
Configure named profiles with aws configure --profile myprofile. Use with aws s3 ls --profile myprofile. Set a default profile with the AWS_PROFILE environment variable. Use aws sts get-caller-identity to verify which account and role you are currently using.

Use --dry-run to test destructive commands
EC2 commands support --dry-run to validate permissions without executing. aws ec2 terminate-instances --instance-ids i-xxx --dry-run returns a DryRunOperation error if the command would succeed, or an UnauthorizedOperation error if permissions are missing.

Paginate large result sets automatically
Add --no-paginate to get all results at once. Or use --page-size and --max-items for manual pagination. The CLI v2 paginates automatically by default for commands like aws s3api list-objects. Use --starting-token with the NextToken value for manual page navigation.

FAQ
The AWS Command Line Interface (AWS CLI) is an open source tool that enables you to interact with AWS services using commands in your terminal. AWS CLI v2 is the current version, available for Windows, macOS, and Linux. Configure it with aws configure and use commands like aws s3 ls, aws ec2 describe-instances, or aws lambda list-functions.
Download from aws.amazon.com/cli or install with pip install awscli. Run aws configure and enter your Access Key ID, Secret Access Key, default region (e.g. us-east-1), and output format (json). Credentials are stored in ~/.aws/credentials. Use aws sts get-caller-identity to verify the configuration worked.
Popular AWS CLI tools: aws-shell — interactive CLI with autocomplete. aws-vault — secure credential storage. awslogs — stream CloudWatch logs. Steampipe — SQL queries over AWS resources. cfn-lint — CloudFormation template linter. This builder generates commands visually without memorizing syntax.
--query uses JMESPath syntax. Examples: aws ec2 describe-instances --query 'Reservations[*].Instances[*].[InstanceId,State.Name]' --output table lists instance IDs and states. aws s3api list-buckets --query 'Buckets[*].Name' --output text lists bucket names. Use --output text for shell script piping.
